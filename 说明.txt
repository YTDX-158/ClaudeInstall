ClaudeInstall — Claude 一键安装/配置工具

作用：一键装好并配好 Claude Code，不用手动装环境，也不用翻墙登录。


用法
────────────────────────────
· 小白：双击「ClaudeInstall安装器_v0.4.4.exe」，跟着向导走（每一步都有图和说明）
· 或者：「ClaudeInstall一键安装.bat」（英文终端版）


向导流程
────────────────────────────
欢迎页 → 【怎么打开 Claude】→【接 DeepSeek ① 注册】→【接 DeepSeek ② 充值拿 Key】
       → 填 Key → 安装 → 完成


它会自动帮你
────────────────────────────
· 装 Node.js —— 没有就自动下载安装（装前验签名）
· 装 Git —— 没有就自动下载安装
· 装 Claude Code —— npm 最新稳定版
· 写好配置 —— 跳过登录，装完直接能用


你只需要做两件事
────────────────────────────
1. 去 platform.deepseek.com 注册 → 实名认证 → 充值（先充 ¥10-20 够用很久）
2. 建一个 API Key，粘进安装器

（这两步向导里也有带图引导，照着走就行）


依赖
────────────────────────────
Node.js（没有会自动下载安装）


提示
────────────────────────────
· 打开 Claude 用普通权限就够了，别用「以管理员身份运行」——界面会错位乱
· 界面万一乱了 → 关掉，用普通方式重开
