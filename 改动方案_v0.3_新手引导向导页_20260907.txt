# ClaudeInstall v0.3 改动方案 · 新手引导向导页

日期：2026-09-07 · 状态：方案定稿（待用户截图 + 确认后实施）
目标版本：v0.3（在 v0.2.2 基础上加新手引导，不改安装逻辑）

---

## 一、要解决的问题
小白双击 exe 走到「填 API Key」页就卡住——不知道 key 从哪来、怎么注册 DeepSeek、
填完还要注意什么。原填 Key 页只有一行字，引导不足。
（顺带解决：cmd 用管理员打开导致 claude 界面渲染乱 = 用户第一会踩的坑）

## 二、方案总览
在 Inno 向导「欢迎页 → 填 Key 页」之间，插入 **3 个带图新手引导页**，每页 1 张图。
向导页可放图（MsgBox 小弹窗放不下图，所以不用弹窗，用整页）。全程不跳出安装器。

新的向导顺序：
```
欢迎页（现有）
  → 【页A】新手说明 · cmd 怎么开（非管理员）+ 界面乱了怎么办   ← 图A（可选）
  → 【页B】接 DeepSeek ① 注册 + 登录 + 实名                    ← 图B
  → 【页C】接 DeepSeek ② 充值 + 建 key + 复制（⚠️只显示一次）  ← 图C
  → 【填 Key 页】（现有）
  → 安装页（现有）
  → 完成页（现有）
```

## 四、iss 具体改动点

### 4.1 版本
```
#define AppVersion "0.3"
```

### 4.2 [Files] 段 —— 把 3 张图打进安装器
图片用 `dontcopy`（不进安装目录，只在向导页用）：
```
Source: "dist_installer\img\guide_cmd.png";  Flags: dontcopy
Source: "dist_installer\img\guide_register.png"; Flags: dontcopy
Source: "dist_installer\img\guide_key.png";    Flags: dontcopy
```

### 4.3 [Code] 段 —— 建 3 个向导页（参考现有 KeyPage 写法）
统一用 `CreateCustomPage`，页面类型选带图的（TBitmapImage 控件放图）。
每页结构：标题 + 一行副标题 + 一张图 + 若干行要点文字。

```
PageA = CreateCustomPage(wpWelcome, '开始之前 · 先看这一页', '怎么打开 Claude');
  → 图A（cmd 搜索框示意）
  → 文字要点：
     · 搜索 cmd → 右键【以非管理员身份运行】（或直接打开）
     · 日常使用用非管理员就够：写代码/读文件/聊天全支持
     · 别用【管理员身份】打开 Claude：界面会错位乱，且没必要
     · 万一界面乱了 → 关掉，用非管理员重开就好

PageB = CreateCustomPage(PageA.ID, '接 DeepSeek ①', '注册并登录开放平台');
  → 图B（登录页截图）
  → 文字要点：
     · 浏览器打开 platform.deepseek.com
     · 手机号或微信登录（新手机号=自动注册，无需填资料）
     · 需实名认证（个人认证 · 传身份证 · 几分钟通过）
     · 未实名 = 无法建 key 和充值

PageC = CreateCustomPage(PageB.ID, '接 DeepSeek ②', '充值 + 拿 key');
  → 图C（充值页 + 建key 合并示意，key 已打码）
  → 文字要点：
     · 左侧【充值】→ 支付宝/微信 → 先充 ¥10-20 够用很久
     · 左侧【API keys】→【创建 API key】→ 命名随意
     · 复制弹出的 sk- 开头的 key（⚠️只显示一次，关窗就没了）
     · 回到安装器，下一步把它粘贴进去
```

### 4.4 现有填 Key 页文案微调
KeyPage 副标题已有"还没有？去 platform 创建"，可改成"照着前面两页注册好，把 key 粘贴这里"
（指向更明确）。

### 4.5 完成页文案扩充（可选）
现有完成页 MsgBox 加一行：如果界面乱了 → 用非管理员重开（和页A呼应）。
