ClaudeInstall v0.2 · 接入 Git 自动安装方案（定稿）
==================================================
存档日期：2026-09-01
状态：定稿待实现

━━ 一、目标 ━━
给"一键安装器"补 Git 地基：
- 缺 Git 的机器自动装好，Claude 完整能力可用（感知文件变更/diff/自动提交）
- 小白装完不卡壳、不翻车、不弹多余疑问
- 不再拿"避免弹窗"当卖点（有 Git 反而会弹"是否初始化仓库"，无害，README 说明即可）

━━ 二、总览（新流程）━━
install.bat（普通用户双击）
  → 顶部 cd /d %~dp0 + 环境检测（Node/Git/Claude）
  → 缺 Node → 下载 → 单独提权静默装（UAC①，弹窗前预告）→ 完整路径验证
  → 缺 Git  → 下载 → 单独提权静默装（UAC②，弹窗前预告）→ 完整路径验证
  → 调 install.js（全程普通用户）
      ① 环境检测复查
      ①.5 npm 镜像（尊重已有：已设非官方则跳过只提示）
      ② 装 Claude
      ③ 填 key（右键粘贴提示 + 回显后4位确认）
      ④ 写配置（普通用户 → 账户必然正确）
      ⑤ 验证（失败内联常见原因）

━━ 三、关键决策 ━━
| 决策点          | 结论                                                       |
|----------------|------------------------------------------------------------|
| 装在哪层        | install.js；bat 只管锁目录 + 环境下载                       |
| Git 装法        | 官方安装器静默装（/VERYSILENT /NORESTART）+ 裁剪组件防右键菜单 |
| 下载源          | npmmirror 镜像 + 固定稳定版本 + 多源兜底 + 校验 + 重试       |
| 版本谁定        | 开发者写死（Node LTS 22.x / Git 2.46.x 稳定版）              |
| 身份模型        | 普通用户全程 + 仅"装 Node/Git"两步单独提权（防配置写错账户）  |
| 失败原则        | 不装死：黄警继续 / 红字 + 官网链接                           |
| 幂等            | 每步"已有则跳过"，重跑安全                                   |

━━ 四、风险与对策（13 条排雷）━━
🔴 雷1 配置写错账户
   → 身份模型重设计：install.js 全程普通用户，仅安装步单独提权（见决策）
🔴 雷2 杀毒拦截 + SmartScreen
   → 安装器改名清晰；开头透明声明"会下载哪些、写入哪些、不上传"；
     README 第一章=放行指南；每步 UAC 前预告；不碰系统深水区
🟡 雷3 npm 镜像覆盖用户设置
   → 装前读现有 registry，已自定义则跳过只提示
🟡 雷4 提权后工作目录变
   → install.js 普通用户全程 + bat 顶部 cd /d %~dp0 + 临时文件统一放 %TEMP%\ClaudeInstall\
🟡 雷5 中断重跑
   → 幂等：每步已有则跳过；下载先写临时文件完成后改名；写配置有 .bak；日志 install.log
🟡 雷6 Node 旧版残留
   → 检测 node < 18 → 黄警 + 静默覆盖升级 LTS，失败提示手动卸
🟡 雷7 cmd 粘贴 key 不灵
   → 提示"右键=粘贴"；支持 --key 绕过；回显后4位确认
🟡 雷8 Git 静默装改右键菜单
   → 组件裁剪（排除右键菜单/Git GUI）；参数太脆则退路=全组件+README说明
🟢 雷9 acceptEdits 默认开
   → 保留（小白体验核心）；README 讲清楚 + 输出提示可关
🟢 雷10 报错看不懂
   → ⑤ 验证失败内联常见原因（key无效/断网/余额不足）+ README 对照表
🟢 雷11 zip 解压阻止
   → README 提示"右键→属性→解除阻止"（M2 出 exe 后消失）
🟢 雷12 磁盘/系统版本
   → 装前检测 Win10+、磁盘剩余 2GB+，不够红警提示
🟢 雷13 key 无确认 → 并入雷7

━━ 五、具体改动（文件清单）━━
1. install.bat：改名清晰 + cd /d %~dp0 + Node/Git 下载与单独提权安装 + 完整路径验证
2. 新增 scripts/lib/download.js：多源下载/校验/重试/进度（Node 自带 https，无新依赖）
3. 新增 scripts/lib/gitInstall.js：ensureGit() 检测→下载→静默装→完整路径验证→失败兜底
4. install.js：插 Git 步 + npm registry 尊重已有 + key 粘贴提示/确认 + 验证失败内联原因
5. scripts/lib/config.js：核对 home 目录归属（普通用户身份下已天然正确）
6. README.md：安全说明 + 放行指南 + 常见报错对照表
7. 说明.txt：同步

━━ 六、验证标准 ━━
1. 干净机器：UAC 2 次（有预告），配置正确落在用户目录，claude 直接能用
2. 已有 Node/Git：全跳过零干扰；已有自定义 npm 镜像：不被覆盖
3. 断网/断源：多源兜底 → 最终红字+官网链接，不装死
4. 装一半关掉重跑：幂等不冲突
5. 无右键菜单污染、无系统深水区改动

━━ 七、范围与顺序 ━━

- CC-Switch 依然不要
- M2 Inno Setup exe 向导 / M3 真机验证 / 分发 仍为后续里程碑
